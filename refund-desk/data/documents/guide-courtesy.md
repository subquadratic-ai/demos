## SEC-GUIDE-COURTESY
Courtesy requests are not a window

Sales sometimes asks support to bend a written refund window for a loud renewal. This guide grants no window and states no number of days that an agent may apply. Courtesy is not an amendment, not a signed agreement, and not the refund handbook. If a customer wants a longer window, the signed file has to say so. A note in this guide does not.
